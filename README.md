# modulo9
RetailPro – Proyecto de Data Analytics

Descripción del proyecto

RetailPro es un proyecto desarrollado como parte de mi formación en Data Analytics. Consiste en analizar los datos de ventas de una distribuidora de productos tecnológicos, con el objetivo de identificar tendencias y obtener información que ayude a tomar mejores decisiones de negocio.

El análisis parte de una situación concreta: investigar el aumento del 20% en las ventas de celulares durante diciembre en clientes de AMBA.

Objetivos del análisis

Analizar las ventas por categoría, región y zona.

Identificar tendencias y comportamientos de compra.

Comparar la evolución de las ventas entre períodos.

Analizar la participación de cada zona en las ventas totales.

Presentar los resultados mediante indicadores y visualizaciones.

Modelo de datos

Para realizar el análisis se trabaja con cuatro tablas principales:

Clientes: contiene información de los clientes y sus características.

Productos: incluye el catálogo de productos, categorías, precios y costos.

Ventas: registra las operaciones comerciales realizadas.

Territorios: contiene información de las regiones y zonas geográficas.

Estas tablas se relacionan entre sí para poder analizar las ventas desde diferentes perspectivas.

Cómo ejecutar los scripts SQL

Para ejecutar las consultas del proyecto se debe contar con SQL Server y SQL Server Management Studio (SSMS).

Abrir SSMS y conectarse a la instancia de SQL Server.

Seleccionar la base de datos correspondiente al proyecto.

Abrir el archivo SQL que se desea ejecutar.

Verificar que las tablas necesarias estén creadas y tengan información cargada.

Ejecutar las consultas con el botón Execute o presionando F5.

Revisar los resultados obtenidos.

Dashboard en Power BI

El proyecto incluye un dashboard para visualizar y analizar los principales indicadores del negocio:

Total de ventas por categoría, región y zona.

Cantidad de unidades vendidas.

Variación de las ventas respecto al promedio del año anterior.

Participación de cada zona sobre las ventas totales.

El objetivo es facilitar la interpretación de los resultados y permitir un análisis más dinámico mediante filtros y visualizaciones.
